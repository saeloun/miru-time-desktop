# Miru Time Tracking 0.1.8

Miru Time Tracking 0.1.8 is a focused design and reliability release for the desktop timer. The app keeps the existing compact menu bar workflow, but makes the most-used screens easier to scan: the running timer is lighter, idle recovery is clearer, and missing profile photos now fall back to a Miru-styled avatar instead of a broken image.

## Highlights

- Lightened the active timer tile so the running state feels connected to the rest of the Miru surface instead of becoming a heavy dark block.
- Tightened the summary, work details, and timesheet spacing so the compact tray window shows more useful entry context without feeling crowded.
- Rebuilt the idle recovery screen as a labeled decision panel with trim-and-continue, trim-and-restart, and keep-idle-time actions.
- Fixed idle timer readability by keeping dark timer text on light idle surfaces.
- Added a Miru-style default avatar for accounts without profile photos, and removed broken-image states from the account button and settings menu.
- Refreshed README screenshots from the packaged Electron app flow.
- Stabilized CI and packaged Electron e2e assertions for avatar fallback and Bun-through-mise builds.
