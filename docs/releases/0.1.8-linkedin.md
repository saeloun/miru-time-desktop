# LinkedIn Draft: Miru Time Tracking 0.1.8

Miru Time Tracking Desktop 0.1.8 is out.

This release focuses on making the menu bar timer calmer and clearer for daily time tracking:

- Lighter active timer state that fits the rest of Miru
- Clearer idle recovery actions for trimming or keeping idle time
- Better spacing and typography in the compact desktop window
- Default Miru-style avatar when a profile photo is missing
- Refreshed screenshots from the packaged Electron app
- Signed and notarized macOS builds, plus Linux and Windows ZIPs
